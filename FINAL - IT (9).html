Local database controls

Browser storage

Transactions and audit events are saved in this browser using local storage, so they remain after refreshing this page on the same browser profile. This is not a shared server database or a secure production database.

Before real deployment: use a server-side database, HTTPS, password hashing, secure session management, role checks on the server, encryption at rest, backups, audit-log protection, and a security review. Never store real passwords or sensitive financial records in browser local storage.
